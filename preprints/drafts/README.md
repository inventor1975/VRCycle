# Working drafts — no-ontology reframe (NOT published)

These are **working drafts**, not published Zenodo versions. They carry the
cycle-wide reframe of the empty set ∅ away from ontology: ∅ is taken as a
**nullary operation** (no ontological primitive), objects are terms over
operations, and the cycle slogan is **"Nothing is — all is doing"**.

The published **VR. A Formal System v1.0.3** (`../VR_formal_system_EN_v1_0_3.pdf`)
already carries this reframe. The three drafts above are preparation; they will be
finalised and posted as new Zenodo versions later (RU versions still pending).
